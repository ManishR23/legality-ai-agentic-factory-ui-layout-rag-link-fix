Stage 4

Normalized Rule Catalog

The BRD converted into deterministic, machine-readable atomic rules. Thresholds live here as parameters -- never as literals in generated code.

Stage 5

Rule Code Generation

One Java 17 class per rule. Every class must override ruleId() -- the execution engine matches compiled rules to catalog definitions by this id alone.

Rule coding prompt

Stage 6

Compile + Auto Fix

Compiles with the real JDK compiler. On failure, a Compile Fix Agent rewrites only what's needed to build -- it is contractually forbidden from changing a threshold, a condition, or a PASS/VIOLATION intent.

Stage 7

Test Schedules

Synthetic crew schedules generated to exercise the compiled rules. Schedule generation is test-data authoring, not a legality decision.

Schedule prompt

Stage 8

Rule Execution & Violations

Every compiled rule runs against every schedule. A crashed rule reports ERROR; a rule that can't reach a verdict reports NEEDS REVIEW -- neither is ever counted as a legality violation.

Stage 9

Grounded Explanation

Explains a schedule or violation you selected in stage 7 or 8, grounded only in the rule catalog and the engine's own output.
